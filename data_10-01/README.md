# 자료구조 - 이진 트리

## 1. 이진 트리란?

이진 트리는 하나의 노드(Node)가 최대 2개의 자식 노드(Child Node)를 가질 수 있는 트리 형태의 자료구조이다.

- 각 노드는 최대 2개의 자식 노드를 가진다.
- 왼쪽 자식 노드(Left Child)와 오른쪽 자식 노드(Right Child)로 구분한다.
- 가장 위에 있는 노드를 루트(Root)라고 한다.
- 자식 노드가 없는 노드를 리프(Leaf)라고 한다.

## 2. 이진 트리의 기본 구조

```text
          A (Root)
         / \
        B   C
       / \   \
      D   E   F
```

## 3. 이진 트리의 종류

### ① 포화 이진 트리 (Full Binary Tree)

모든 노드가 자식 노드를 0개 또는 2개 가지고 있는 트리이다.

### ② 완전 이진 트리 (Complete Binary Tree)

마지막 레벨을 제외한 모든 레벨이 꽉 차 있으며, 마지막 레벨은 왼쪽부터 순서대로 채워지는 트리이다.

### ③ 정 이진 트리 (Perfect Binary Tree)

모든 내부 노드가 자식 노드 2개를 가지고 있으며, 모든 리프 노드의 깊이가 같은 트리이다.

### ④ 편향 이진 트리 (Skewed Binary Tree)

모든 노드가 왼쪽 또는 오른쪽 한 방향으로만 연결된 트리이다.

## 4. 이진 트리 순회 (Tree Traversal)

트리의 모든 노드를 특정한 순서로 방문하는 방법이다.

### ① 전위 순회 (Preorder)

**Root → Left → Right**

```text
방문 순서: A → B → D → E → C → F
```

### ② 중위 순회 (Inorder)

**Left → Root → Right**

```text
방문 순서: D → B → E → A → C → F
```

### ③ 후위 순회 (Postorder)

**Left → Right → Root**

```text
방문 순서: D → E → B → F → C → A
```

### ④ 레벨 순회 (Level Order)

루트부터 시작하여 각 레벨을 왼쪽에서 오른쪽 순서로 방문한다.

```text
방문 순서: A → B → C → D → E → F
```

## 5. 이진 트리의 특징

- 하나의 노드는 최대 2개의 자식 노드를 가질 수 있다.
- 노드의 개수가 증가하면 트리의 높이도 증가할 수 있다.
- 탐색, 삽입, 삭제 등의 작업에 활용할 수 있다.
- 트리의 구조에 따라 탐색 효율이 달라진다.

## 6. 내용 정리

1. 이진 트리는 노드 하나가 최대 2개의 자식 노드를 가지는 자료구조이다.
2. 루트는 가장 위에 있는 노드이다.
3. 리프는 자식 노드가 없는 노드이다.
4. 전위 순회는 부모 → 왼쪽 → 오른쪽 순서이다.
5. 중위 순회는 왼쪽 → 부모 → 오른쪽 순서이다.
6. 후위 순회는 왼쪽 → 오른쪽 → 부모 순서이다.
